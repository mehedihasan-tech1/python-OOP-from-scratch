Python OOP Learning:
A collection of python code examples and practical exercises created while learning Object-Oriented-Programming (OOP) in Python


This repository documents my learning journey through fundamental OOP concepts, including classes, constructors, inheritance, and other essential programming techniques.


Topics Covered:
- Constructors: Understanding the __init__() method and object initialization.
- Class Variables: Learning how class attributes are shared among instances.
- Inheritance: Learning how one class inherits attributes and methods from another.
- Multiple Inheritance: Understanding how a class can inherit from multiple parent class.
- Multilevel Inheritance: Exploring inheritance across multiple levels of classes.
- Super(): The function-Learning how to access methods and constructors from parent classes.



Explation of class topic:
- Constructor: A constructor is a special method that initializes an object when you create it.
- __init__(): A special method that initializes a newly created object
- self: Refers to the current object
- Class Variables: A class variable in python is a variable that belongs to the class itself and is shared by all instances (objects) of that class
- Inheritance: Inheritance is an OOP concept that allows one class to acquire the attributes and methods of another class. it helps us reuse code and avoid unnecessary repetition.
- Multiple inheritance: inherit from more than  one parent class
- Multilevel inheritance: inherit from a parent which inherit from another parent
- Abstract Class: A class that cannot be instantiated on its own; Meant to be subclassed. 
    They can contain abstract methods, which are declared but have no implementation. Abstract class benefits:
    1. Prevents instantiation of the class itself
    2. Requires children to use inherited abstract methods
- Super(): The function used in a child class to call methods from a parent class (superclass). Allows you to extend the functionality of the inherited methods
